# Portafolio de Joel Martínez

Portafolio profesional enfocado en desarrollo web, soporte TI y soluciones con inteligencia artificial.

## Características

- Modelo 3D interactivo renderizado con WebGL, sin dependencias externas.
- Diseño responsive para escritorio, tableta y móvil.
- Secciones de perfil, investigación, proyectos, tecnologías y contacto.
- Descarga directa del CV actualizado.
- Compatibilidad con `prefers-reduced-motion`.

## Desarrollo local

Requiere Node.js 22.13 o superior.

```bash
npm ci
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Compilación

```bash
npm run build
```
